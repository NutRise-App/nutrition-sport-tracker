# Contributing to NutRise Backend

Bu repo üzerinde yapılan tüm çalışmalar, kontrollü bir mühendislik disipliniyle yönetilmektedir.

## Branch İsimlendirme Standartları
Yeni işler için aşağıdaki ön ekleri kullanıyoruz:
- `feat/`: Yeni özellikler (feature)
- `fix/`: Hata düzeltmeleri
- `test/`: Test ekleme veya düzeltme
- `ci/`: CI/CD ve otomasyon işleri
- `chore/`: Dependency, Docker veya bakım işleri
- `security/`: Güvenlik çalışmaları
- `docs/`: Dokümantasyon

## Commit Mesajı Standartları
Commit mesajlarınızın ilk satırı kısa ve açıklayıcı olmalıdır (örn: `feat: add user registration endpoint`).
