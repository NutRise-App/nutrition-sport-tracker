# NutRise Backend

NutRise Backend is a Spring Boot REST API developed for NutRise, a nutrition and fitness tracking mobile application.

The backend provides secure authentication, meal logging, water intake tracking, workout records, daily summaries, and scheduled user reports.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Meal logging and nutrition tracking
- Water intake tracking
- Workout logging
- Daily user summary
- Daily and weekly scheduled report generation
- MySQL database integration
- Dockerized backend structure
- Railway deployment support

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL
- Maven
- Docker
- Railway
